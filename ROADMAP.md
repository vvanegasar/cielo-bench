# Roadmap

Dates are targets in Colombia time (UTC−5). Each milestone ends with a changelog entry.

| Milestone | Target | Definition of done | Status |
|---|---|---|---|
| **v1.0 — The instrument** | Nov 2026 | Domain-independent harness; astronomy domain (144 pairs, 18 templates, JPL Horizons ground truth); tabular enterprise-data domain (126 pairs, synthetic SQLite); pressure × tool × premise design with fault injection; deterministic scorer; Wilson and cluster-bootstrap intervals, McNemar–Holm contrasts and power analysis; read-only MCP server; CI; harness validation with simulated agents | Done |
| **v1.1 — First real-model results (one provider)** | Nov 2026 | Runs on frontier models from one provider with pinned versions (Claude Haiku 5.5 on both domains; Claude Sonnet 5.5, Claude Opus 5.5 and Claude Fable 5.2 on astronomy, with a matched four-model comparison); `results/<run>/` with report, figures, summary and packed, sanitized trials; README results table filled from the generator; results note; agent-assisted audit of the tabular evidence rule | Done (2026-11-23). Redefined from "two providers": the second provider and the manual error analysis moved to v1.2 |
| **v1.2 — A harder test** | Dec 2026 | Premises close to the truth (golden set `astronomy-near-v2`, ADR-0009); pilot of that set on one model; **multi-turn insistence after the check** as a new condition, with its scorer, metric, simulated-agent validation and tests; runs on the four Anthropic models of v1.1 on the harder conditions; scorer support for longer `VALUE: unknown (…)` forms | In progress. Done 2026-11-24 and 25: golden set v2, scorer change, a Haiku pilot that showed the floor holds with near premises (`docs/results/2026-11-near-premises-pilot.md`). Redefined after the pilot and an external design review: distance alone does not break the floor, and insistence alone risks a third floor, so the line is a distance ladder × framing × insistence (control: neutral challenge). The ladder is built and calibrated (grey zone found, design frozen); next: preregister on OSF, then the confirmatory runs. See `docs/RESEARCH_PLAN.md` and `docs/PREREGISTRATION.md` |
| **v1.3 — Second provider and broader coverage** | Q1 2027 | A frontier model from a second provider, pinned, on the same designs; manual error analysis of the real transcripts, including a hand-coded count of numbers stated in the prose under faults; golden set v2 of the full astronomy design (fixes the `sets_first` and `rises_first` items; the near set already does for its templates); tabular domain to 15+ templates; dataset card and dataset on Hugging Face; MCP Registry listing | Planned |
| **v1.4 — New conditions** | Q2 2027 | Free-form answers instead of the VERDICT line; an "act vs. answer" contrast; a human-approval condition for agents that act; group pressure; a third domain (official statistics) | Planned |

Out of scope for now: a web UI, accounts, any commercial use.
